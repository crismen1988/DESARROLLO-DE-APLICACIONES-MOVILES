# 003 Favoritos, eventos y reportes

## Objetivo

Permitir personalizacion para usuarios y participacion de la comunidad turistica.

## Reglas

- Un usuario no puede guardar dos veces el mismo POI.
- Solo el propietario elimina sus favoritos.
- Los eventos deben tener fechas coherentes y un estado publicable.
- Los reportes identifican POI, motivo y usuario creador.
- El usuario crea reportes; el listado y cambio de estado son administrativos. Consultar o retirar reportes propios no esta implementado.
- Los datos privados nunca aparecen en endpoints publicos.
