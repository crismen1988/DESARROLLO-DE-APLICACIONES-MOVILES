# 002 Catalogo turistico

## Objetivo

Publicar categorias y puntos de interes con ubicacion, precios, horarios, imagenes y calificaciones.

## Reglas

- El listado y detalle publico solo muestran POIs activos.
- Latitud y longitud deben estar dentro de rangos validos.
- Solo proveedores verificados o administradores crean y modifican POIs.
- Un proveedor solo modifica sus propios POIs.
- Las eliminaciones son logicas cuando existan referencias.
- Los listados se paginan y usan filtros permitidos.
